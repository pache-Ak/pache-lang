## 函数（运算符）签名生成规则

函数签名由 函数名， 参数类型生成

运算符应生成特殊的函数名，且与普通函数名不冲突，
普通函数名的字符集只包含标识符，运算符都不在标识符内，
因此将运算符包含在函数名生成的签名中，可以有效避免与普通函数冲突。

运算符除了类型导致的重载外，还有参数数量导致的重载，后者可以在词法分析阶段分析出，
对于不同参数数量分运算符生成不同的签名，可以有效减少重载集的大小，进一步加快编译。

函数调用和多维数组的参数数量不固定，
参数数量也应成为签名的一部分。

现设计一下的运算符签名，
**"O" + 参数数量 + 运算符**

参数数量以十六进制表示，不含有前缀后缀。
虽然设计上没有对参数数量作限制，但考虑到常规用法，参数数量通常很小。
